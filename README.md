# Rojgar

**Rojgar** is a full-featured freelancing web application designed to connect **coders, editors, and service providers** with customers seeking services. Our platform aims to create a **functional and active community** while giving freelancers a **higher probability of landing work**. The project is built using modern web technologies and follows best practices for scalability and maintainability.

---

## **Tech Stack**
- **Frontend / Backend:** JavaScript  
- **Database:** Prisma + SQL  
- **Containerization:** Docker  
- **API Testing:** Postman  

---

## **Problem Statement**
Freelancers often struggle to find consistent work and visibility in crowded marketplaces. Rojgar addresses this problem by:  
- Creating a **ranked community of service providers**  
- Prioritizing users based on **skill, quality, and quantity of work**  
- Facilitating **direct connections between service seekers and providers**  
- Providing an **engaging leaderboard system** to motivate and reward top performers  

---

## **Features**
- **User Authentication & Profiles:** Secure registration and profile management  
- **Service Listings:** Freelancers can list services and showcase skills  
- **Job Matching:** Customers can find service providers efficiently  
- **Leaderboard & Ranking:** Users ranked based on work quality and quantity  
- **Community Engagement:** Active discussion forums for coders, editors, and other service providers  
- **Local Deployment:** Fully functional locally via Docker containers  

---

## **Unique Selling Proposition (USP)**
- **Higher probability of getting work** for freelancers  
- **Skill-based leaderboard** rewarding high-quality contributions  
- **Community-driven platform** fostering collaboration and learning
